## ゲームシステム

### 心拍数

プレイヤーの心拍数（0～200）がゲーム全体に影響を与えます。

- **初期値**: 100
- **上昇要因**: 攻撃を受ける、攻撃する、時間経過
- **下降手段**: 「心拍を抑える」操作で減少（弱: 秒間5、強: 秒間15）

#### 心拍数による効果

| 心拍数 | 効果 |
|--------|------|
| 100未満 | 攻撃力上昇（最大+50%）、画面ブラー・ズーム演出、黒オーバーレイ |
| 100付近 | 通常状態 |
| 100以上 | 攻撃速度上昇、赤オーバーレイ演出 |
| 170以上 | 血管エフェクト出現 |
| 200到達 | スタン（一定時間行動不能） |

#### 心拍を抑える

- **弱**（R1 or L1 / RB or LB / L or O）: 移動しながら心拍を下げられる（速度低下あり）
- **強**（R1 + L1 / RB + LB / L + O）: 移動不可だが減少速度3倍。居合ゲージも高速蓄積
- 心拍を抑えている間、減少量に応じて**攻撃力バフ**が蓄積される（最大1.75倍係数）

#### 居合

心拍を抑える操作中にゲージが100%になると居合が発動可能になります。

- **弱で5秒** / **強で2秒**の維持で発動条件達成
- 条件達成後に**攻撃ボタン（J / □ / X）**で居合発動
- 居合ダメージ: 基礎攻撃力 × 5倍（心拍数補正で最大250%ボーナス）
- 発動時に心拍数が25刻みで上昇

### 吸収ゲージ

敵への攻撃やパリィで蓄積するゲージです。

#### 蓄積方法

| 行動 | 蓄積量 |
|------|--------|
| 弱攻撃ヒット（Jak_0 / Jak_1 / Jak_2） | 5 / 10 / 15 |
| 強攻撃ヒット | 2 |
| 回避パリィ成功 | 5 |

#### 使用方法

- **回復**（R / ○ / B）: 吸収ゲージを消費してHPを回復

### パリィ（回避居合い）

敵の攻撃タイミングに合わせて回避すると**回避パリィ**が発動します。

- **パリィ可能攻撃**: 居合モーション + ダメージ + 敵スタン + 吸収ゲージ+5
- **パリィ不可攻撃**（大技等）: ダメージなし、吸収ゲージ+5、専用SE再生
- 大技中のパリィ: 0.5秒スタン
- 大技中の居合: 5秒スタン + 大技中断 + 無敵解除

## チュートリアル

タイトル画面からチュートリアルシーンに移行できます。
各操作を段階的に学べるステップ形式で、入力監視による完了判定があります。

- **ポーズ**（ESC / ≡）: 入力監視中に説明ウィンドウを再表示
- **長押し**（ESC / ≡）: タイトルに戻る
- チュートリアル全完了後、自動でゲームシーンに移行
